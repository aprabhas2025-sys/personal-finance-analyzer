# Hynex dashboard

A responsive React + TypeScript + Tailwind dashboard with Recharts and Lucide icons. It is a standalone frontend alongside the existing Streamlit finance app.

## Run locally (Windows CMD)

```cmd
cd /d "C:\Users\prabhas\Downloads\mini project\finance-analyzer\hynex"
npm install
npm run dev
```

Open the local URL Vite prints (normally `http://localhost:5173`). Stop the dev server with `Ctrl+C`.

The charts, transactions, and assistant use sample data and mock responses; no health or financial data is sent to a service.
